# 拆解:Grok Bot「百万撤离」游戏海报

- 来源:用户提供(2026-11-07),Grok Bot 团队「百万撤离」战绩海报;画面含 Delta Force(三角洲行动)撤离射击游戏元素.
- 风格分类:海报封面(游戏海报/战绩海报).
- 时间:2026-11-07 收入储备.

## 设计语言

### 整体风格
电影感游戏海报 + Q 版 3D 角色 + 撤离射击游戏 HUD.黄昏金色时刻的战争电影氛围,配上可爱化(Q 版)的战术小队,严肃与俏皮并存;右侧叠加游戏结算界面,让海报本身就像一张游戏截图.

### 构图:三层纵深
- 前景:5 名 Q 版角色一字排开,战术装备(迷彩,战术背心,头盔),头部各不相同(白色机器人圆头,戴眼镜少年,粉色三角,绿色方块,小白机器人),是 Grok Bot 团队各成员的头像化身.
- 中景:直升机(旋翼转动)+ 工业塔架,交代撤离场景.
- 远景:落日金色天空 + 镜头光晕,暖色主调,营造"凯旋"情绪.
- 右侧:游戏结算 HUD(撤离成功,本局收益,带出物品,返回大厅按钮),把"战绩"这个信息直接做进画面.
- 底部:4 张队员卡片(头像 + 名字 + 分数:GROK BOT 428,763;铁柱AGI 362,471;栗山 287,539;必胜客 169,920),像游戏结算的队员榜.
- 左缘:手写体标语(部分可见),作装饰性点缀.

### 字体与色彩
- 标题:超大 3D 金属金字"Grok Bot 百万撤离",立体浮雕 + 金属质感,是视觉锚点;副标题"安全撤离 · 任务完成"用细白字压在标题下方,留白分隔.
- 色彩:主色是黄昏金(橙金)+ 军绿迷彩 + 黑;金色标题与落日呼应,暖色统一全图;右侧 HUD 用深蓝灰底 + 青绿高亮("撤离成功"),冷暖对比让界面信息跳出来.
- 字体层级:标题最大(3D 金属),HUD 数字次之(收益金额),队员名字和分数最小;信息按"标题 > 战绩 > 队员"递减.

### 角色设计
- Q 版比例:大头小身,约 2.5 头身;战术装备画得很细(迷彩纹理,背心口袋,枪械),可爱外形 + 硬核装备的反差是记忆点.
- 头部即身份:每个角色的头就是其网络头像(机器人,三角,方块等),不用写名字也能认出是谁;团队海报的聪明做法——头像即 ID.

## 为什么好
- 一张图同时完成三件事:庆祝战绩(百万撤离),展示团队(5 名队员),讲清玩法(撤离射击 + 收益结算),信息密度高但不乱.
- 金色黄昏 + 金属标题的暖色统一,让复杂的游戏 HUD 和多名角色不显杂.
- Q 版角色降低了军事题材的严肃感,适合社群传播;头像即 ID 的设计让团队成员有归属感.

## 可借鉴的点
- 战绩/里程碑海报:大标题 + 一句话副标题 + 结算式数据面板(收益/物品/队员榜),数据本身就是内容.
- 团队海报:用每个成员的头像(而非真人照片)做角色,统一画风后排成一排,归属感强且易复制.
- 标题用 3D 金属字做视觉锚点,副标题细字压在下方,大小对比拉开层级.
- 游戏 HUD 可以直接做进海报:结算界面,收益数字,返回按钮都是现成的设计元素,不用重新发明.
- 暖色主调统一全图(落日 + 金标题),再用一个冷色小面积点缀(青绿"撤离成功"),冷暖对比让关键信息跳出来.
