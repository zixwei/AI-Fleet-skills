# 拆解:Linear / Vercel 极简深色 UI

- 来源:Refero Styles<Linear design system>https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1 ;925studios<Linear Design Breakdown: Why Every SaaS Team Copies This UI>https://www.925studios.co/blog/linear-design-breakdown-saas-ui-2026 .
- 风格分类:界面空间(产品界面/设计系统).
- 时间:Linear 与 Vercel 为 2020 年代开发者工具代表;参考文章为 2026 年整理.

## 设计语言

### 整体风格
深色优先,超极简,精确,键盘优先.黑暗不是主题,而是基底;界面像一台午夜精密仪器,安静,克制,没有多余装饰.

### Linear
- 颜色:近黑底色(#08090a),纸白文字,一个电光酸性绿强调色(#e4f222)只用在主操作和激活状态;另一版本用靛蓝/紫(#5e6ad2)作强调.灰阶为主,强调色极少出现.
- 边界:0.5px 细线边框,不用阴影做层级;几何形状本身承担分隔作用.
- 圆角与间距:6px / 12px 圆角,8–12px 紧凑内边距,4px 间距网格(所有元素对齐到 4 的倍数).
- 字体:Inter,全站统一;大标题字距 -0.022em,正文字重 400–510(偏轻,不用粗黑).
- 文字层级:大部分文字与图标在 40–60% 不透明度,只有状态,优先级,交互元素才用全饱和色.

### Vercel
- 颜色:纯黑白,非黑即白,Geist 字体系统.
- 边界:用 shadow-as-border 技术(0px 0px 0px 1px 的 ring 阴影)代替 CSS 边框,视觉上更干净.
- 圆角:6px 标准,9999px 药丸徽章,64–100px 导航药丸.

### 设计哲学
- 深色模式是品牌定位,不是偏好设置:默认深色等于告诉用户"这是给 builder 的工具",借用代码编辑器的视觉语言.
- 速度是设计语言:Linear 加载 <200ms,视图切换 <100ms;乐观 UI(新建 issue 立刻出现在列表,后台再调接口),骨架屏,积极缓存,让每次交互都感觉零延迟.
- 键盘优先:Cmd+K 命令面板才是真正的产品;按 C 新建,按 . 开菜单,G+I 跳收件箱;快捷键不是功能,是核心设计哲学.
- 指挥面板,看板,AI 面板是界面上唯一的视觉纹理,其余一切保持安静.

## 为什么好
- 黑暗作基底,让几何与排版自己说话,不靠阴影和装饰撑场面.
- 强调色极少出现,出现时一定有意义(操作或状态),所以一眼能看到.
- 速度与键盘优先让工具感觉"快",快本身就是品牌体验的一部分.
- 整体足够 cohesive,以至于成了整整一代 B2B 工具的默认模板.

## 可借鉴的点
- 深色优先 + 一个强调色,且强调色只用在操作与状态上,别处一律灰阶.
- 细线边框代替阴影;4px 间距网格;字重偏轻,字距收紧.
- 大部分文字用 40–60% 不透明度,只有该看的地方才全色.
- 速度即设计:反馈要立刻给(乐观 UI),不要让用户等.
- 与现有规范的关系:海军蓝+金是"亮色金融"路线,Linear 是"深色工具"路线;做仪表盘,工具类页面,空间界面时用 Linear 这套,做对外传播的数据图时用海军蓝+金.
