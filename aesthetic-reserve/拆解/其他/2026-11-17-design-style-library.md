## 每期四件套

每期都包含: 15-20 秒动效短片 (1920x1080, 30/60fps, 配乐与音效全部由代码合成, 成片在 Releases), 4 张风格图/布局图 (1080x1350, X/小红书竖图比例, 手写 SVG, `images/*.svg`), 制作过程 (`PROCESS.md`, 研究、令牌、风格图、分镜、改版、质检、发布, 每步怎么想、怎么做、踩了什么坑), 完整源码 (Remotion 或 three.js, `audio/make_music.py`).
另有: 风格指南/布局指南 (历史、规则、色板、字体、版式、常见误区、AI 提示词, 在各期 `README.md`), 设计令牌 (同一份颜色/字体/线宽, 视频、图片、网页共用, `tokens.ts`、`tokens.css`、`tokens.json`), 从 0 到 1 (003 期起, 用了哪些工具、按什么顺序、每步敲什么命令、做到什么程度算过关, 附开工提示词, `MAKING.md`).

|---|---|---|---|

## 统一规格

- 时长: 15 秒 = 900 帧 @ 60fps; 所有转场都落在拍点上 (包豪斯、瑞士 120 BPM, 1 拍 = 30 帧; 便当盒 150 BPM, 1 拍 = 24 帧; 瀑布流约 128.6 BPM, 1 拍 = 28 帧).
- 结构: 钩子 (0-2 秒) -> 6-9 个侧面章节 (每章 1-1.5 秒: 一个主角 + 一个动作 + 一行标签) -> 回顾 -> 片尾.
- 风格图: 海报、速查卡、今天的应用、图案/纹理, 四张一组. 布局图: 海报、速查卡、布局 x 风格 (或易混布局对照)、拿来就用的模板, 四张一组.
- 字体: 只用可免费商用的开源字体 (SIL OFL / GUST Font License / Apache 2.0).

## 技术栈与本地运行

- 渲染: Remotion + three.js, 配乐用 Python 合成 (`audio/make_music.py`).
- 要求: Node.js 22.12+、Python 3.10+、ffmpeg、Git. 画廊另需已登录的 GitHub CLI, 不需安装渲染依赖.
- 关键命令: `git clone https://github.com/guanmo-ai/design-style.git`, `npm ci`, `npm run fonts` (下载开源字体到 public/fonts), `pip install -r requirements.txt`, `npm run studio` (浏览器逐帧预览、改参数), `npm run render:001` (生成配乐后渲染成片), `npm run images:001` (生成图案、内嵌字体的 preview SVG + 2x PNG). 各期同理, 如 `render:009`、`render:L01`.
- 给 AI 安装: 帖子说"开源仓库丢给 AI 安装". 仓库自带给做片子的 Claude 的说明 `CLAUDE.md` 和做新片的 skill `.claude/skills/style-film/`. CLAUDE.md 要点: 目标按顺序是 X 爆款、动效顶尖、对设计师真的有帮助; 必须守的只有八条, 见 `docs/DESIGN_NOTES.md` 开头, 其余文档都是参考不是硬性要求; 动效底线是毛绒那期, 交片前跑 `python3 drafts/_lib/smooth.py <成片.mp4>` 逐个核对跳变; 云端 4 核无显卡, WebGL 走 SwiftShader, 先用最小页面测一帧多少秒再定画质, 渲染要能断点续渲.

v6.6 要的视觉多样性可从这里取参考, 最贴的几项: 013 装饰艺术 (金色只给线, 与海军蓝 + 金锚点合, 其余画面不用整幅刷金), 009 新粗野主义 (黑框 + 硬阴影, 适合数据卡), 001 包豪斯 (几何 + 三原色, 适合章节标题), 002 瑞士 (网格 + 大字, 适合事实卡), 003 构成主义 (斜线 + 大字, 适合涨跌段), 024 水墨 (东方意象, 可作过场).
注意: 该仓库本身用 Remotion 渲染, 用户 2026-11-17 定过动效走技能库里的 anime-js / motion / motion-canvas / ola, 这份只作审美参考, 不直接套用其渲染链. 15 秒结构 (钩子 0-2 秒 -> 每章一个主角 + 一个动作 + 一行标签 -> 回顾 -> 片尾) 与用户定的 3 秒规则、每 2-3 秒一个视觉变化合拍, 可直接借.
