# 审美储备

zixwei 的公共审美储备库.存放已定稿的配图与设计规则,以及用户发来的好设计的拆解与解读.供舰队所有成员共用.

## 风格分类
不同风格的设计分开存放,分别归类.现有分类:
- 金融信息图:海军蓝+金数据可视化(X 配图,数据图).
- 海报封面:小红书金融鄙视链海报风,文章主图(暗金奢华电影感).
- 卡通插画:零基础教程卡通风格配图.
- 界面空间:仪表盘与空间设计(Agent-Fleet空间).
- 其他:暂未归类的新风格,先放这里,攒多了再单独立类.

## 规则
- 做图,做帖,做教程,做空间时,配图与设计按<设计规则.md>执行.
- 用户看到好的设计,图片,视频或网站,发给 gmuse;gmuse 拆解解读后写进本目录(拆解/ 子目录,按风格分类,每则一个文件),标注来源与时间.
- 每则拆解必须标明风格分类;新风格先放"其他",攒多了再单独立类.
- 写入规则前,先把用户原话改成 AI 能听懂的提示词语言(结构化,无歧义:写清适用范围,执行步骤,条件),再写入.

## 文件
- 设计规则.md:现行全部配图与设计规则(按风格分类).
- 拆解/:好设计的拆解档案,按风格分类存放.
