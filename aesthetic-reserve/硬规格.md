## 7. Linear / Vercel 极简深色 UI

来源: 拆解/界面空间/2026-11-06-linear-vercel-minimal-ui.md; 原出处 Refero Styles、925studios 文章. 以下全部为拆解正文已核实.

- Linear 色板: 近黑底色 #08090a; 纸白文字; 强调色电光酸性绿 #e4f222, 只用在主操作和激活状态; 另一版本用靛蓝/紫 #5e6ad2 作强调; 灰阶为主, 强调色极少出现.
- Linear 边界: 0.5px 细线边框, 不用阴影做层级; 几何形状本身承担分隔作用.
- Linear 圆角与间距: 6px / 12px 圆角; 8–12px 紧凑内边距; 4px 间距网格 (所有元素对齐到 4 的倍数).
- Linear 字体: Inter, 全站统一; 大标题字距 -0.022em; 正文字重 400–510 (偏轻, 不用粗黑).
- Linear 文字层级: 大部分文字与图标在 40–60% 不透明度, 只有状态、优先级、交互元素才用全饱和色.
- Vercel 色板: 纯黑白, 非黑即白; 字体 Geist.
- Vercel 边界: shadow-as-border 技术 (0px 0px 0px 1px 的 ring 阴影) 代替 CSS 边框.
- Vercel 圆角: 6px 标准, 9999px 药丸徽章, 64–100px 导航药丸.
- 速度 (设计语言的一部分): Linear 加载 <200ms, 视图切换 <100ms; 乐观 UI (新建 issue 立刻出现在列表, 后台再调接口); 键盘优先: Cmd+K 命令面板, C 新建, . 开菜单, G+I 跳收件箱.
- 与海军蓝+金关系: 海军蓝+金是"亮色金融"路线, Linear 是"深色工具"路线; 仪表盘、工具类页面、空间界面用 Linear 这套, 对外传播的数据图用海军蓝+金.

## 8. Claude Imagine — Visual Creation Suite

来源: 拆解/界面空间/2026-11-06-ohayou792-claude-imagine-visual-suite.md; 原出处 X @ohayou792 2026-11-01 帖子 (Claude 内部规范, 拆解为摘要, 非原文转载). 以下全部为拆解正文已核实.

- 模块 (5 选 1, 每件作品只用一个): diagram (流程图/结构图), mockup (UI 原型/表单/卡片/仪表盘), interactive (可交互讲解), chart (图表/数据/地图), illustration (插画/生成艺术).
- 配色: 每件作品配色上限 2–4 色; 用 Claude 色阶 (HSL token, 每色 9–12 阶), 不用硬编码色值; HTML 用 CSS 变量表示文字色; 表面按透明 tint 处理. 具体色号: 未核实 (规范本身要求用 token 不用硬编码, 拆解未收 token 表).
- 动效: 缓动曲线统一; 微交互 300ms; 滚动触发的分区过渡 1000ms; 滚动揭示内容要克制、有意; 禁用廉价动效 (弹跳、旋转、弹性); 禁用 emoji; 禁用线性渐变 (只用纯色或至多一个径向渐变); 禁用装饰性图形.

- 深色模式: 强制要求; 深色配色比浅色更饱和; 每对明暗值都要成对给出.
- 原则 (硬规则): 每个元素都要有存在的理由, 删掉一切无用之物; 每个渐变、边框、阴影、动效都要解决一个视觉问题; 尺寸、间距、线条都按同一系统校准.

## 9. MUJI / 原研哉「空」

来源: 拆解/其他/2026-11-06-muji-kenya-hara-emptiness.md; 原出处 Blake Crosley 文章、madegooddesigns MUJI 品牌指南.

- 字体: 拉丁字标用 Helvetica (最中性的字体, 正因为中性才合适). 字号: 未核实.
- 做法 (硬规则): 留白要留真的空白, 不要把每个角落都填满; 空白是邀请, 不是缺失; 一个小标志 + 一片大空场, 比满版信息更有力量.

- 空与简单的区别 (先问再动手): 简单是去掉多余让人看清, 空是去掉多余让人自己填; 做品牌、做封面、做空间时, 先问"我要让人看清, 还是让人自己填".
- 与海军蓝+金关系: 海军蓝+金是"满"的路线 (信息密度高, 数字最大), MUJI 是"空"的路线; 严肃数据图用满, 品牌海报、封面、留白时刻用空.

## 11. design-style 开源设计风格库

来源: 拆解/其他/2026-11-17-design-style-library.md; 原出处 guanmo-ai/design-style 仓库 (https://github.com/guanmo-ai/design-style), 网页画廊 https://guanmo-ai.github.io/design-style/. tokens 原出处已核实 (2026-11-20, 仓库当前提交 5fdd828).

### 统一规格 (拆解正文 + 仓库 README 已核实)

- 时长: 15 秒 = 900 帧 @ 60fps (个别 18–21 秒, 见各期); 所有转场都落在拍点上.
- 结构: 钩子 (0–2 秒) → 6–9 个侧面章节 (每章 1–1.5 秒: 一个主角 + 一个动作 + 一行标签) → 回顾 → 片尾.
- 风格图: 1080×1350 (X/小红书竖图比例), 手写 SVG; 动效短片 1920×1080, 30/60fps.
- 字体: 只用可免费商用的开源字体 (SIL OFL / GUST Font License / Apache 2.0).
- 技术栈: Remotion + three.js; 配乐用 Python 合成.
- 拍点: 包豪斯、瑞士 120 BPM, 1 拍 = 30 帧; 便当盒 150 BPM, 1 拍 = 24 帧; 瀑布流约 128.6 BPM, 1 拍 = 28 帧; 其余各期见下表.
