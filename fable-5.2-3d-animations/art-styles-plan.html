100 Art Styles — Plan

A second set of 100 animations, next to the existing 100 styles of the 3D Style Atlas. Status: plan only. No code is written. Date: 2026-11-13.

0. Why a second set

The existing 100 styles are complete visual ideas: a material, a scene type or a metaphor (for example Marble Run, Ant Farm, Sushi Belt). About 20 of them are art styles in the usual sense (a way to draw or paint). About 80 are scenes, machines or metaphors. This split is a judgment, not a field in the code.

Each existing style file also mixes the look and the content. For example, atlas/styles/soft-clay.js holds fixed beats ("Start with $100", "20 years: $673"), a fixed years table and fixed legend labels. No style takes a new topic without a rewrite.

The goal of the second set: 100 art styles — ways to draw, such as watercolor, paper cut or linocut — that work on any scene.

1. Main idea: separate the art style from the scene

The kit already has most of what is necessary. atlas/kit/stage.js:282-303 has a post pass. It gives a full-screen shader three images of the rendered 3D scene: the colour (tColor), the depth (tDepth) and, if requested, the surface directions (tNormal). Edges, paper grain, brush strokes, dots and colour limits can all come from these. Today 11 of the 100 existing style files use a post shader. The other 89 set post: null.

animation = scene     (what happens: objects, camera, beats, topic)
          + art style (how it is drawn: shader, materials, palette, frame step)
  • Art style file (atlas/art/<id>.js): name, description, post shader, an optional material change (for example flat colours with no shading), a palette, a frame step (for example "on twos" for a hand-drawn feel). It has no topic.
  • Scene file: like an existing style file. It has build, update, beats and a topic.
Result: 100 animations. Also, any art style works on any scene: 100 art styles × 10 scenes = 1,000 combinations with no extra code. Each new art style can take a new topic.

Overlap with the existing 100

About 15 existing styles are already art styles. Examples: Pencil Sketch, Ink and Toon, Woodblock Print, One-Bit Dither, Low-Poly, Voxel, Stained Glass, Thermal Camera, X-Ray. The draft list does not repeat them (see decision 1).

Hard cases

The post pass sees only the final picture, so some styles need more than a filter:

  • Pixel art: render at a low size, then scale up. Needs a small kit change.
  • Knit, cross-stitch, mosaic: a grid shader can make them.
  • Cubism: needs several camera views in one frame. Expected to be the hardest. It can drop out.

4. Phases

Warning: the rule in HANDOFF.md says "no subagents without the owner's approval". Phase 3 uses subagents. Start Phase 3 only after the owner approves the number of agents.
  1. Phase 0 — decisions and list. The owner answers the 4 decisions in section 5 and changes the list. Output: the final list, in a new section of HANDOFF.md.
  2. Phase 1 — kit and pilot. No agents. Add to stage.js:
    • a way to put a scene and an art style together;
    • an optional material change;
    • a low-res render option;
    • a frame step option.
    Keep the file below the 500-line limit (355 lines now). Then build 2 art styles (watercolor, linocut) on 2 scenes. The owner reviews the result before Phase 2.
  3. Phase 2 — scenes. Option A: choose 10 existing animations and check each one under 3 filters. Option B: write 10 new scenes.
  4. Phase 3 — 100 art styles, in parallel. Each art style is its own file, so agents do not edit the same files. Plan: 5 agents at a time, 1 group of 10 styles each, 2 rounds (the session limit is fewer than 10 agents). Each agent writes only atlas/art/<id>.js files. Only the lead agent edits the shared files (manifest, kit, gallery), so there are no merge conflicts.
  5. Phase 4 — checks.
    • Extend atlas/tools/test.mjs: no errors, the same frame each time for the same t, no blank frames.
    • Render all 100 art styles on the same scene at the same time, on contact sheets. Compare the pairs by pixel difference and flag pairs that are too similar. This check answers "is each one really different", which is not answered for the existing 100.
    • Make 100 posters.
  6. Phase 5 — gallery and prompt.
    • index.html: a second tab, "Art styles", from a second manifest.
    • player.html?art=<id>&scene=<id>: choose any art style and any scene.
    • Copy prompt: the prompt contains the art style file and the kit. Claude then applies that drawing method to the user's topic.
