# 优惠券过期前提醒

领了一堆券放着不用，过期了才想起来，等于白领。
Muse 帮你把券的到期日记好，快过期时提醒你顺手用掉，不让优惠白白作废。
**你可以这样跟 Muse 说：**
1. 我这几张券帮我记一下到期时间；
2. 到期前一天提醒我还没用；
3. 提醒的时候顺便告诉我能买什么。
