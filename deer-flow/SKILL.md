# deer-flow 深度研究智能体平台 + 技能集

字节跳动开源的深度研究智能体平台:多轮研究、咨询级报告、数据分析、多模态生成(图、音乐、播客、PPT、视频),另有 HTTP API(见 claude-to-deerflow 技能).技能在 `skills/public/`(23 个),另有 `.agent/skills/`(4 个维护技能).

## 怎么用

1. 按任务读 `skills/public/<名字>/SKILL.md`;不知道用哪个读 find-skills.
2. 要调平台能力(远程研究)读 claude-to-deerflow.
3. 咨询级报告(SWOT、PESTEL、波特五力、GB/T 7714-2015 引用)读 consulting-analysis.
4. 应用源码已收、跑平台去上游:backend/ 与 frontend/ 全套文本已入库(见下);部署运行去上游.

## 与库里已有技能的分工

库里已有 frontend-design(Anthropic 官方)与 skill-creator;deer-flow 内含同名技能(`skills/public/frontend-design`、`skill-creator`)是平台自带的另一份,用 deer-flow 时读平台内这份,不与库顶层条目混用.
