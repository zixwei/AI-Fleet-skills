# Box 文件管理

公司文件都在 Box 里，找版本、看评论、分享，来回点很费时间。
Muse 能搜、读、传、改 Box 里的文件，还能管评论和分享。你负责说文件名，它负责找到。
**你可以这样跟 Muse 说：**
1. 帮我找一下 Box 里最新那版方案；
2. 这个文件分享给项目组；
3. 这个文件上次是谁改的？有评论吗？
