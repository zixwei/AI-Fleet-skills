# Workflow 02: 내용 기반 장면 찾기 (자막+비전 하이브리드)

사용자가 시간을 모르고 장면을 설명만 할 때, 자막 + 키프레임 비전으로 매칭하여 컷.

## 입력 예시

- "강아지 처음 등장하는 장면 잘라줘"
- "그분이 매출 얘기하는 부분만 추출해"
- "환영 인사 구간만 남겨"

## 처리 단계 (비용 통제 정책 적용)

1. **사전 검증 게이트** (SKILL.md §2)
2. **자막 생성** — `node scripts/transcribe.mjs <input.mp4>`
   - 영상 길이별 모델 자동 선택 (<30s tiny, <5min base, <30min medium, 이상 large-v3)
   - 결과: `<input>.words.json` (단어별 타임코드)
3. **자막 매칭** (Claude 추론)
   - 사용자 설명과 단어 시퀀스 의미 매칭
   - 각 후보 구간에 신뢰도 점수(0-1) 부여
4. **신뢰도 분기**:
   - **>= 0.8**: 비전 스킵, 후보 ±2초 마진으로 즉시 컷 단계로
   - **< 0.8**: 비전 보강 단계 진입
5. **비전 보강** (필요 시만)
   - 후보 ±5초 범위에서 `node scripts/extract-keyframes.mjs --threshold 0.3`
   - `node scripts/grid-frames.mjs <frames-dir> --cols 3 --rows 3`로 합성
   - Claude vision 1회 호출로 그리드 평가
   - 비전 점수 + 자막 점수 가중합 (자막 0.6, 비전 0.4)
6. **최종 타임코드 확정** + dry-run:
   ```bash
   capcut cut --from <start> --to <end> --dry-run --project <draft-dir>
   ```
7. **사용자 승인** -> 실제 실행 -> `capcut info` diff
8. **로깅** — 자막/비전 사용 여부, 신뢰도, 최종 선택 구간

## 신뢰도 점수 기준 (가이드)

| 매칭 강도 | 점수 |
|-----------|------|
| 자막에 사용자 키워드 완전 일치 + 단일 문장 | 0.9-1.0 |
| 의미 매칭 + 중복 없음 | 0.8-0.9 |
| 의미 매칭 + 후보 2-3개 | 0.5-0.8 |
| 키워드 미매칭 / 후보 다수 | < 0.5 |

## 비용 통제 (`references/token-budget.md`)

- 비전 호출은 신뢰도 < 0.8일 때만
- 키프레임은 후보 ±5초만 추출 (보통 5-15장)
- 3x3 그리드로 합성 -> 호출 횟수 N/9로 축소
- 영상이 5분 이상이면 사용자에게 "Whisper medium 모델 사용. 약 X분 소요 예상" 안내

## 실패 시 폴백

- 자막 추출 실패 (whisper 미설치): 사용자에게 설치 안내 + 비전 단독 경로 제안 (느림)
- 후보 0개: "설명과 매칭되는 구간을 찾지 못했습니다" + 사용자에게 키워드 보완 요청
- 후보 다수 (>= 5): 상위 3개 시간/요약을 표로 제시 -> 사용자 선택
