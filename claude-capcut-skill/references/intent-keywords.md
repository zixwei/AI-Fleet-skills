# Intent Keywords Reference

스킬 자동 트리거 + 워크플로우 분류에 사용되는 키워드 사전. SKILL.md 라우터의 1차 (키워드) / 2차 (컨텍스트) / 3차 (negative) 판단 근거.

---

## 1. 1차 키워드 (스킬 후보 진입)

다음 중 1개 이상 등장 시 스킬이 후보가 됨.

### 한국어
| 키워드 | 변형 |
|--------|------|
| 캡컷 | 켑컷, 캡컷프로, 캡컷 프로 |
| 컷편집 | 컷 편집, 영상편집, 영상 편집 |
| 자막 | 캡션, 자막 생성, 자막 입히기 |
| 무음제거 | 무음 제거, 무음 컷, NG 제거 |
| 쇼츠 | 숏폼, 세로 영상, 9:16 |
| 토킹헤드 | 토킹 헤드, 말하는 영상 |
| 하이라이트 | 하이라이트 추출, 하이라이트 컷 |
| 스마트컷 | 스마트 컷, 자동 정리 |

### 영어
| 키워드 | 변형 |
|--------|------|
| capcut | CapCut, capcut pro |
| jianying | JianYing, 剪映 |
| video edit | video editing, edit video |
| silence cut | remove silence, dead air |
| subtitle | caption, srt, ass |
| shorts | short-form, 9:16, vertical |
| talking head | talking-head |
| smart cut | smartcut |

### 명시 호출
| 패턴 | 워크플로우 |
|------|-----------|
| `/capcut` | 인터뷰 모드 진입 |
| `/capcut doctor` | 환경 검증 |
| `/capcut help` | 인터뷰 모드 |
| `/capcut <intent>` | 해당 인텐트 직접 라우팅 |

## 2. 2차 컨텍스트 조건 (스킬 확정 발화, AND)

1차 키워드가 매칭되어도 다음 중 최소 1개 충족해야 발화:

- [ ] CapCut/JianYing/capcut/켑컷/캡컷 단어가 사용자 발화에 명시
- [ ] `draft_content.json` 또는 CapCut 프로젝트 폴더 경로 언급
- [ ] `/capcut` 명시 호출
- [ ] 영상 파일(.mp4/.mov/.m4v) + CapCut 컨텍스트 동시 존재

---

## 3. 3차 Negative Patterns (오발화 차단)

다음 패턴은 1차 키워드가 매칭되어도 스킬을 비활성화한다.

| 패턴 | 이유 | 처리 |
|------|------|------|
| "캡쳐 (screenshot/스크린샷)" | "캡컷"과 발음 유사 | 비활성 |
| "쇼츠 (쇼핑/단축)" 단독 | 쇼핑 컨텍스트 | 영상 컨텍스트 없으면 비활성 |
| "자막" + 코드 파일 (.srt/.vtt 없이) | i18n 문자열 작업 가능성 | i18n 키워드 있으면 비활성 |
| 일반 ffmpeg/mp4 컷 (CapCut 무관) | video 스킬 영역 | `skills/video/`로 위임 |
| "캡컷 vs Premiere" 등 비교/리뷰 질문 | 정보 요청 | 발화하지 말고 일반 답변 |
| "캡컷 설치 방법" 등 설치 문의 | 일반 정보 | doctor 안내만 출력 후 종료 |

### 거짓 양성 테스트 케이스
- "스크린샷 캡쳐 좀 해줘" -> 비활성 OK
- "쇼핑몰 단축 URL" -> 비활성 OK
- "캡컷 어떻게 깔아?" -> doctor 안내만
- "이 mp4를 mov로 변환" -> video 스킬 위임

## 4. 인텐트별 키워드 -> 워크플로우 매핑

| 패턴 | 워크플로우 |
|------|-----------|
| 시간 패턴 (`\d+:\d+`, `\d분`, `\d초`) + 컷/트림/속도 | 01 |
| "찾아서", "그 장면", "···하는 부분" + 컷/추출 | 02 |
| "무음", "NG", "스마트컷", "자동 정리" | 03 |
| "쇼츠", "세로", "숏폼", "9:16", "하이라이트" | 04 |
| "자막", "캡션", "번역", ".srt 만들어" | 05 |
| "보여줘", "검사", "되돌려", "롤백", "백업" | 06 |
| "템플릿", "저장", "적용" | 07 |
| "모자이크", "얼굴 가려", "번호판", "프라이버시" | 08 |
| "배경 블러", "보케", "크로마키", "그린스크린", "필터", "트랜지션", "디졸브", "블렌딩", "말풍선" | 09 |
| "따라다니게", "추적", "모션 트래킹", "오브젝트 따라" | 10 |
| "색보정", "LUT", "시네마틱", "빈티지", "흑백", "톤", "색조" | 11 |
| "안정화", "손떨림", "잡음 제거", "노이즈", "shake", "stabilize", "denoise" | 12 |
| "켄 번스", "줌인", "팬", "애니메이션", "페이드", "타이핑", "타이프라이터" | 13 |
| "다국어 자막", "동시 자막", "···어 같이", "한영 자막" | 14 |

중첩 시 우선순위: 시간 패턴(01) > 명시적 워크플로우 키워드 > 일반 키워드.

## 5. 인터뷰 모드 트리거

다음 조건에서 인터뷰 모드 진입:
- `/capcut`, `/capcut help` 명시 호출
- 1차/2차 통과 후 어떤 워크플로우에도 분류 불가
- 사용자가 "뭘 할 수 있어?" 같은 메타 질문
