# 更新日志

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。网站随 `main` 持续发布，因此按日期记录。

## 2026-11-18（第五次更新）

### 新增
- **Elastic 弹性控件**（`gallery/originals/elastic.html`）：拉伸开关、蠕动分页点、橡皮搜索、弹性标签栏、压键播放、购物袋角标、弹性折叠卡、鼓包音量条。参考 @yui540 弹性 UI 的视觉语言（浅灰底板、粗圆角近黑控件、压缩回弹），没有复刻原视频中的控件，卡片标注「参考后实现」。
- 图鉴共 232 个示例。

## 2026-11-18（第四次更新）

### 新增
- **Gestures 手势与物理**（`gallery/originals/gestures.html`）：滑动确认、下拉刷新、弹弦、多米诺、翘板开关、波形拖动、吸附网格、扇形菜单、步骤条、呼吸球。全部单色、无文字、可键盘操作。
- **8 款单色原创加载动效**：双星、电平、绕方、摆锤、回字、缺环、方阵蛇、翻块。
- 「浮字」加载动效改为英文 “Loading”。图鉴共 224 个示例，原创 64 个。

## 2026-11-18（第三次更新）

### 新增
- **Motion 微交互**（`gallery/originals/motion.html`）：扇形卡组、纵深卡堆、封面流、倾斜卡片、磁吸按钮、文字翻转、菜单变形、错落入场。其中 7 个参考 amicro（MIT）的卡片排布与过渡类型，独立实现，卡片标注「参考后实现」。
- 「多彩」分类：色轮、拉绳灯、抛硬币与昼夜开关单独成组，排在「全部 UI」最后（`gallery/originals/color.html`）。

### 调整
- 全站与原创控件改为极简单色（中性黑白灰），去掉偏蓝紫的强调色；原创加载动效在图鉴中也以单色预览。
- 原创控件页面全部改为英文：按钮文字、提示、读屏标签、标题与页脚，测试会检查不含中文。
- 首屏按钮改为「试试果冻方块」。图鉴共 206 个示例。

## 2026-11-18（第二次更新）

### 新增
- **8 个无文字的图形交互**（`gallery/originals/visual.html`）：磁吸点阵、果冻方块、色轮、融合水滴、拉绳灯、抛硬币、涟漪画板、花朵开关。
- **6 个原创操作反馈**（`actions.html`）：复制按钮、点赞爆发、纸飞机发送、下载进度环、验证码、通知铃。
- **6 个原创表单控件**（`inputs.html`）：划线清单、石子评分、档位滑块、密码强度、标签输入、方案卡片。
- **8 款原创加载动效**（`gallery/loaders/motifs.mjs`）：潮环、叠块、节拍、浮字、点阵波、沙漏、文稿、时针。
- 首屏优先展示无文字的图形交互；图鉴共 198 个示例，其中原创 45 个。

### 调整
- 简化署名规则：参考想法的作品只在 `works.js` 的 `credit` 字段标注，CREDITS.md 不再逐条维护；通用交互模式不需要标注。
