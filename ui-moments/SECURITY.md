# 安全策略

UI Moments 是一个静态网站和一组可复制的前端示例，没有服务器端代码，也不收集用户数据（收藏和主题只保存在你自己浏览器的 `localStorage` 里）。

## 支持的版本

只维护 `main` 分支和线上站点 <https://guanmo-ai.github.io/ui-moments/>。

## 报告漏洞

如果你发现了安全问题（例如导出的代码可被注入脚本、嵌入协议可被跨源滥用、依赖存在可利用漏洞），**请不要公开提交 issue**，请使用 GitHub 的 [私密漏洞报告](https://github.com/guanmo-ai/ui-moments/security/advisories/new)。

请尽量附上：受影响的页面或文件、复现步骤、可能的影响。我们会在 7 天内回复，并在修复发布后致谢报告者（如果你愿意）。
