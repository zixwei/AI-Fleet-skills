# 组件分类与展示

每条记录对应一个可直接体验的 UI。主分类根据交互如何触发、用户能做什么来划分。卡片标注来源，详情保留作者署名和许可。

## 主分类

| 分类 | 判定标准 | 当前示例 |
| --- | --- | --- |
| 交互控件 | 点按、切换或拖动后改变一个值或状态 | 原创控件（Core / Visual / Motion / Actions / Forms 五组）、昼夜开关、弹性滑尺、对齐拨片、夹页键 |
| 点击反馈 | 点按后播放一次短反馈并恢复初始状态 | 12 款 Micron 效果，包括果冻回弹、左右抖动、淡闪 |
| 多彩 | 依赖颜色才能成立的作品，单独成组、排在最后 | 昼夜开关、色轮、拉绳灯、抛硬币 |
| 加载动效 | 在等待期间自动播放，提示任务仍在进行 | 19 款原创动效、44 款 LDRS、47 款 Loading UI、46 款 SVG Spinners |

「全部 UI」优先展示可操作的控件与原创作品，穿插不同用途和形态的精选示例。点击反馈可按回弹、摆动、闪动筛选。加载动效可按环形、圆点、线条、几何、文字、字符、图标、状态筛选。文字动效基于可读文案，字符动效把字形当作图形单元，状态形态对应骨架屏等内容占位。

## 卡片操作

卡片上部用于体验。交互控件可直接操作，点击反馈可重复触发，循环加载动效可暂停和继续。卡片底部统一打开详情。加载动效在详情内支持调整参数、复制或下载代码，导出示例随实现附带对应的 MIT 许可。

画廊由 `assets/catalog.mjs` 合并 `gallery/works.js`、原创加载动效和各个上游组件目录。嵌入组件使用 `?embed=ui`，同源消息用于跟随主题、暂停离屏动画。

构建后运行 `npm test` 检查组件索引、日期逻辑、导出和上游许可。浏览器检查使用 `npm run package:site` 生成的发布目录，运行 `npm run test:browser`。
