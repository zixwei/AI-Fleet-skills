# Stripe 收款管理

做生意收款在 Stripe 里，客户、发票、退款都要登后台看。
Muse 能管你的 Stripe 客户、产品、优惠、发票和订阅。退款、发支付链接、对账，说一句它就处理。
**你可以这样跟 Muse 说：**
1. 帮我给这个客户发一个支付链接；
2. 这个月 Stripe 到账多少？
3. 这笔重复扣款帮我退掉。
