# hyperframes

Source: https://github.com/heygen-com/hyperframes @88c22a7 (Apache-2.0, 87347 stars, verified 2026-11-20). Video skills from the X video-skills roundup (2026-11-19, @Tynric_carter).

Only the skills/ directory is kept; the framework source (packages/, registry/ blocks, examples/) and the 73 MiB docs/ catalog snapshots are upstream, not part of the skill.

## Sub-skills

- `hyperframes`: Read first to make, edit, animate or render any video with HyperFrames (HTML rendered to video), including launch films, explainers, music videos, charts, maps, See `skills/hyperframes/SKILL.md`.
- `hyperframes-cli`: HyperFrames CLI - scaffold, check frames, edit timelines, preview, render, share and project history; read JSON and recover from failures. See `skills/hyperframes-cli/SKILL.md`.
- `hyperframes-registry`: About 450 ready-made HyperFrames blocks and components installed as editable source - transitions, overlays, titles, kinetic type, captions, charts, map overlay See `skills/hyperframes-registry/SKILL.md`.
- `media-use`: Get or make any media for a HyperFrames video - music, sound effects, images, icons, logos, voiceover, avatar and generated video, transcripts, cutouts, colour See `skills/media-use/SKILL.md`.
- `remotion-to-hyperframes`: Bring existing video code or footage into HyperFrames and verify it frame by frame against the original - Remotion first, also Motion Canvas, Lottie, Three.js, See `skills/remotion-to-hyperframes/SKILL.md`.
- `reverse-any-video`: Rebuild any video file as an editable HyperFrames project - motion graphics, talking heads, live action or AI-generated footage - checked against the original f See `skills/reverse-any-video/SKILL.md`.
- `slideshow`: Build a HyperFrames slideshow to present live - slides, fragment reveals, branching hotspots and presenter mode with speaker notes, served by `hyperframes prese See `skills/slideshow/SKILL.md`.
- `style-sampling`: Make a new episode in a proven video style - Collage Explainer, Finance Explainer, Animated Science Explainer, 3D Brand Explainer, 3D True Crime - on the person See `skills/style-sampling/SKILL.md`.
- `figma`: Bring Figma into a HyperFrames video - rendered assets, brand tokens, components, storyboard frames as reconstructed motion (frames read as states, not slides), See `skills/figma/SKILL.md`.
