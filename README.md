# AI-Fleet-skills

AI 舰队公开技能库：只放技能内容，不含任何记忆，不含舰队规则。

- 这里是 zixwei 的 AI 舰队（AI Fleet）共用的技能库，45 个 `[方法]`类技能全文 + 索引 `SKILLS-INDEX.md`，任何 AI 不用授权就能直接读全文、照着做。
- 技能是技能、规则是规则：舰队规则 `zixwei-decisions` 不在这个库里，单独在公开规则库 [zixwei/AI-Fleet-rules](https://github.com/zixwei/AI-Fleet-rules)（`SKILL.md` + `DECISIONS.md` 全文）；舰队分工见公开库 [zixwei/AI-Fleet-division](https://github.com/zixwei/AI-Fleet-division)。
- 记忆不在这里。所有记忆都在私有库 [zixwei/AI-Fleet-memories](https://github.com/zixwei/AI-Fleet-memories)，按“产品-名称-记忆”三级分类存放，绝不写入公开库。
- 技能原文来自私有库 `AI-Fleet-memories` 的 `shared/skills/`，每次舰队体检（每周六）同步更新。

## 用法

任务匹配到某个技能时，读该技能目录下的 `SKILL.md` 全文，按“何时用”行事；需要子技能时读 `skills/<名字>/SKILL.md`。索引见 `SKILLS-INDEX.md`（索引中提到的规则类技能 `zixwei-decisions` 全文在规则库，不在技能库）。
