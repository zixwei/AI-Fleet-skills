# 事实类问题：先查全再下结论

官网没写，不等于这件事不存在。很多规则只写在条款细则、后台页面或用户讨论里。

## 步骤
1. **官方来源**：官网帮助中心、条款/协议全文（逐条看编号条款，比如 3.4）、FAQ、官方博客或公告、开发者文档。注意页面日期。
2. **后台入口**：如果问题涉及账户设置（绑定收款、PayPal、Billing、Payout），去找后台里的具体菜单名。查不到就写明「后台未核实」。
3. **第三方教程**：用英文、中文、日文各搜至少一次（例如 "<platform> affiliate PayPal setup"、"<平台> 联盟 绑定 PayPal"、"<プラットフォーム> アフィリエイト PayPal 設定"），优先看近 12 个月的。
4. **论坛和社区**：Reddit、官方社区论坛、知乎/V2EX、X 上的讨论，看有没有和官方说法冲突的真实经历。
5. **交叉核对**：官方和第三方说法冲突时，以最新的官方条款为准，并把冲突写出来；第三方独有的说法标「未经官方确认」。

## 下结论时
- 只有在 1–4 都查过之后才能说「不需要」「不存在」「做不到」这类否定结论；没查全就说「官网未提及，教程/论坛未查」。
- 每条结论附上来源链接和页面日期，分开写「已核实」和「未核实」。
- 之前说错了，就马上更正，并说明是哪一条来源推翻了原结论。
